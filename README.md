# Youtube-Analyzer
* Developed an AI-powered YouTube Video Analyzer using Agno Agent and Groq LLM to extract captions,
generate transcripts, and perform intelligent video content analysis.
* Integrated YouTubeTools to process video URLs and automatically classify video topics by leveraging
LLM-based semantic understanding.
* Built and deployed an interactive Streamlit application, enabling real-time transcript generation, summarization,
and content insights through an intuitive user interface.
* Implemented an end-to-end Agentic AI workflow by combining AI agents, LLM inference, and automated content analysis for efficient video understanding.

**Tech:** Python, Streamlit, Agno Agent, Groq API, YouTubeTools
